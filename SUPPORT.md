# Support

Use the repository issue tracker for reproducible bugs and feature requests. Include:

- LinkedDraw version or commit;
- browser and operating-system versions;
- LinkedIn interface language;
- exact steps and expected/observed behavior;
- sanitized console output.

Do not post credentials, cookies, access tokens, signed media URLs, private profile HTML, or personal screenshots. Report security vulnerabilities privately as described in `SECURITY.md`.

LinkedDraw is community-maintained software and has no guaranteed response time or support SLA.
