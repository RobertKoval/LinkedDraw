# Store submission material

- `listing-en.md`: English Chrome/Firefox listing copy.
- `listing-uk.md`: Ukrainian localized copy.
- `permission-justification.md`: host and storage explanations for review forms.
- `artifacts/store/linked-draw-editor.png`: generated at Chrome Web Store's 1280×800 screenshot size by `npm run screenshots`; review it before uploading.

Store dashboards, signing credentials, extension IDs assigned by a store, and final signed artifacts are intentionally not stored in this repository.
